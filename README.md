# CTRLurLife

CTRLurLife is a life-oriented task tracking application designed to help users improve balance, consistency, and self-awareness across multiple life domains.

Rather than focusing solely on task completion, CTRLurLife provides structure and feedback that encourage intentional productivity and sustainable habits.

---

## Project Motivation

Many task tracking tools overwhelm users with features while failing to address behavioral patterns such as neglecting health, academics, or personal time. CTRLurLife addresses this gap by organizing tasks into life domains and providing insight into how effort is distributed over time.

---

## Core Features (Planned)

- Create, update, and delete tasks
- Organize tasks by life domain (e.g. School, Health, Work, Personal)
- Assign priorities and due dates
- Track task completion history
- Generate simple completion summaries by domain

---

## Technology Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Build Tool:** Maven
- **Database:** H2 (embedded, development)
- **Frontend:** Thymeleaf (initial prototype)
